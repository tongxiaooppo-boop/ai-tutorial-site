第 2 天｜環境：VS Code、Git、GitHub 各做什麼？

白話觀念卡

VS Code 是編輯程式檔案的工作桌；Git 是保存在自己電腦上的版本紀錄；GitHub 是放置與分享專案的線上服務。三者各有用途。

按儲存，只保存目前內容。Git 的 commit 則像替一組檔案留下「存檔點」，日後能比較修改、找回版本。commit 還在本機；push 才是傳到 GitHub。

今天先把環境準備好，建立一個小專案與存檔點。不要讓 AI 從整個桌面或下載資料夾開始工作，避免讀到私人文件。

示範工具

  • 首選：Gemini 免費版作為操作教練。貼上少量安裝訊息，就能請它解釋下一步，不需要另外購買程式代理。
  • ChatGPT：也適合解釋 Windows 指令與 Git 訊息；它沒有看到畫面時，需要你提供實際文字。
  • Claude：也能協助排除環境問題；聊天帳號與 Claude Code 使用資格分開。

VS Code、Git 與 GitHub Free 才是今天實際操作的工具，AI 負責解釋。

步驟

  1. 打開瀏覽器，安裝 VS Code。開啟本課「官方連結」裡 Microsoft 的 VS Code Windows 安裝說明，選適合電腦的安裝檔。一般個人電腦可使用 User Installer；安裝時保留加入 PATH 的選項。
  2. 安裝 Git for Windows。從 Git 官方 Windows 安裝頁下載，一般設定可先沿用預設值。完成後重新開啟 VS Code。
  3. 建立 GitHub Free 帳號。使用自己的信箱或支援的登入方式，完成信箱驗證；啟用雙重驗證，復原碼自己保管。
  4. 建立專案。用檔案總管在自己的文件資料夾新增 fx-practice，在 VS Code 選「File → Open Folder」開啟它。建立 README.md，貼入昨天確認的規格並儲存。
  5. 檢查 Git。在 VS Code 選「Terminal → New Terminal」，確認目前位置是 fx-practice，執行下列指令。姓名可用暱稱；信箱請換成 GitHub「Settings → Emails」顯示的 noreply 信箱，不要原樣使用範例。
  6. 確認存檔點。查看最後一筆紀錄，再執行 git status，確認沒有尚未提交的修改。

第 5 步指令請逐行執行：

git --version
git init -b main
git config user.name "你的暱稱"
git config user.email "換成GitHub顯示的noreply信箱"
git add README.md
git commit -m "建立匯率換算器規格"

第 6 步：

git log -1 --oneline
git status

這裡的 Git 姓名、信箱設定只套用在目前專案。user.email 是版本紀錄資訊，不是登入密碼。

範例提示詞

請協助我檢查Windows程式入門環境，先解釋，不執行或建議刪除檔案。

<環境資料>
作業系統：Windows。
編輯器：VS Code。
專案資料夾：fx-practice。
我已安裝Git，並重新開啟VS Code。
執行的指令：git --version。
實際結果：
【貼上終端機輸出；先移除姓名與私人路徑】
</環境資料>

請輸出：
1. 這段訊息的白話意思。
2. 目前能確認什麼、還不能確認什麼。
3. 下一個檢查動作，一次只給一個。
4. 成功時大約會看到什麼。

不要要求我提供密碼、驗證碼、復原碼或存取權杖。
不要把Git安裝成功，當成GitHub已登入或檔案已上傳。

驗收

  • 是／否：VS Code 左側只開啟 fx-practice 專案？
  • 是／否：git --version 顯示版本，git log -1 --oneline 看得到存檔紀錄？
  • 是／否：知道 commit 在本機，今天尚未發布網站？

正常範例

輸入：執行 git status。
預期：顯示目前分支為 main，並有 nothing to commit, working tree clean 等工作目錄乾淨的訊息。

失敗範例

輸出：git is not recognized 或「無法辨識 git」。

辨識方式：這表示目前終端機找不到 Git，與 HTML 程式無關。先確認安裝完成並重新開啟 VS Code，再檢查；不要開始重寫作品。

常見錯誤
  • 把 VS Code 與 Visual Studio 混為同一套軟體。
  • Git 裝好卻沒重新開啟終端機，誤以為安裝失敗。
  • 在桌面根目錄或整個文件資料夾執行 git init。
  • 用真實私人信箱建立公開版本紀錄，之後才發現信箱也跟著公開。
  • 把 GitHub 密碼、驗證碼或復原碼貼給 AI；登入應在官方登入畫面自行完成。
