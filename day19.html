第 3 天｜讓 AI 動手：完成第一次修改

白話觀念卡

聊天型 AI 通常把程式給你，再由你貼入檔案。程式代理則能在授權範圍內讀取專案、修改檔案、執行指令。方便的同時，也必須知道它開了哪個資料夾、取得哪些權限、改了什麼。

擴充功能可以免費安裝，但服務可能需要付費資格。Codex 官方目前將 Free 的使用範圍列為逐步開放的桌面 App；不能保證免費帳號能用 VS Code 擴充功能。Claude Code 也不能直接用 Claude Free 聊天資格代替。

示範工具

① 使用 Gemini／Claude／ChatGPT 網頁聊天提供修改文字；②使用已開通的 Codex 桌面版或 Claude Code 桌面版；③使用 VS Code 的官方擴充功能；④用任一 AI 提供文字，再自行存回本地。

Codex Plus 的 IDE 資格可確認，Free／Go 的 IDE 資格官方說法未一致；Claude Code 需符合資格的付費訂閱或另行付費的 Console／供應商存取。今天不用為了繼續課程輸入信用卡，可改走①。

步驟

今天只在規格最後新增「版本：第 3 天練習」。先留存檔點，使用下方提示詞；一次只改一件事，改完就存，不承諾免費可改固定輪數。

路線①：網頁版

  1. 在 AI 網頁貼入現有 README.md 與提示詞，取得要加的一行；聊天不會直接改電腦檔案。
  2. 在 GitHub 開啟 README.md，進入編輯器，貼入該行。
  3. 核對只有一行變動，Commit changes，重新開檔確認。

路線②：桌面 App

  1. 開啟昨日 clone 的專案；Codex 使用沙箱，Claude 先 Plan 確認範圍，再以 Manual 檢查修改。
  2. 送出提示詞，核對提議只改 README.md；不要同時讓兩個代理改同一份檔案。
  3. 在 GitHub Desktop 的 Changes 檢查 diff，填 Summary、Commit to main、Push origin；到 GitHub 確認。沿用第 2 天安全邊界。

路線③：VS Code

  1. 在 VS Code 開啟 fx-practice，先用 git status 確認規格有存檔點。
  2. 按 Ctrl＋Shift＋X，安裝一個官方擴充功能：Codex，發行者 OpenAI、識別碼 openai.chatgpt；或 Claude Code，發行者 Anthropic、識別碼 anthropic.claude-code。
  3. 開啟擴充功能面板並在官方流程登入；不具資格就回①。Claude 擴充功能內含所需 CLI，不必先另外安裝終端機版。
  4. 先用唯讀／Plan 看專案，再提出修改；核對接受的內容，執行：
git diff -- README.md
git add README.md
git commit -m "加入課堂版本標示"

不因舊文章先安裝 WSL，也不為省事開 Full Access 或 Bypass。

路線④：本地小作品

  1. 用任一 AI 依提示詞提供那一行文字。
  2. 開啟本地規格副本，貼上並另存 規格-v2.txt。
  3. 比較 v1 與 v2，確認只多指定的一行，舊檔保留。

範例提示詞

請協助我完成第一次小修改，先確認範圍，再處理。

<專案資料>
目前專案：fx-practice。
目標檔案：README.md；路線④請改成自己的本地規格副本。
需求：在文件最後新增一行「版本：第 3 天練習」。
其他內容不需要調整。
這是入門練習，不需要套件、網路連線或系統設定變更。
</專案資料>

請先回答：
1. 你要讀取哪個檔案（聊天工具請以我貼上的內容為準）？
2. 預計修改哪個位置？
3. 我要怎麼確認只有這項修改？

若你具有本機修改能力，依目前權限模式提出或完成這項修改，
最後列出實際修改檔案與檢查方式。
若你只是聊天工具，請直接提供我要貼上的那一行，
不要說已經修改我的電腦檔案。

驗收

  • 是／否：能找到指定版本標示，且只有預期的一行變動？
  • 是／否：知道是自己貼回檔案，還是代理在授權範圍內修改？
  • 是／否：修改後已留下提交紀錄或新的副本？

正常範例：要求新增版本標示，只有 README.md 或規格副本多一行。

失敗範例：AI 說「環境已最佳化」並新增設定檔或修改系統設定；停止接受，逐檔檢查範圍。

常見錯誤
  • 以為裝好擴充功能就取得免費模型額度。
  • 把 VS Code 內建代理選單與另外安裝的官方擴充功能混在一起。
  • 以為代理每個動作都會詢問；自動模式可能直接修改工作區檔案。
  • 為了省事選擇完整存取、Bypass，卻不知道開放了哪些範圍。
  • 把專案中的秘密檔案開在編輯器，誤以為 .gitignore 也會禁止 AI 讀取。
