第 17 天｜把想法寫成規格

★ 最低完成路線先修：第 1–3 天
這七天要做什麼

每天約 60–90 分鐘。全程沿用同一個作品，從固定練習匯率開始，逐步加入官方資料、公開網址與除錯能力。

天數 今天完成什麼
第 1 天 寫出看得懂、能驗收的作品規格
第 2 天 選擇工具路線，存下第一個版本
第 3 天 讓 AI 協助完成第一次小修改
第 4 天 做出單一 HTML 匯率換算器
第 5 天 下載官方匯率 JSON 並匯入，練習保護金鑰
第 6 天 公開網站，或完成本地作品
第 7 天 回報錯誤、比較修改，練習還原

① 網頁版是免費主線，取得完整 HTML 後，用 GitHub 網頁完成版本紀錄、部署與排程，不必安裝 VS Code。

路線 給誰 要準備什麼 要不要付費 終點
① 網頁版 沒訂閱、不想安裝軟體 免費 AI 網頁版＋GitHub 帳號 可免費完成；AI 有用量限制 換算器、API、Pages、Actions
② 桌面 App 有訂閱或 Codex 桌面已開通 Codex 桌面版或 Claude 桌面版的 Code＋免費 GitHub Desktop Codex Free／Go 逐步開放；Claude Code 要 Pro 以上等符合資格方案 同①
③ VS Code 想學完整開發環境 VS Code＋官方擴充功能＋Git＋GitHub 編輯器與 Git 免費；代理另需資格 同①
④ 本地小作品 不想公開作品或卡關太久 任一 AI＋可存純文字的編輯器＋瀏覽器 可用免費 AI，受用量限制 單一 HTML 雙擊能用，不部署、不排程

怎麼選

  • 沒訂閱、不想安裝：選①；Claude Design 可匯出獨立 HTML，Gemini 可複製程式碼。
  • 有訂閱：可選②或③；先確認帳號實際開通資格。
  • 不想公開作品，或卡關太久：選④，完成本地作品也算達標。
  • 四家都沒有承諾免費能修改幾次；一次只改一件事，改完就存。

全週共同約定：練習金額皆為虛構。作品只做數值換算與資料說明，不推薦換匯時機、不預測漲跌，也不代替銀行的實際交易報價。

第 1 天｜Vibe Coding：把想法說成可以驗收的工作

白話觀念卡

Vibe Coding 是用自然語言描述需求，讓 AI 協助產生程式，再透過實際操作反覆修改。你不用先背語法，但要說清楚「輸入什麼、按了會怎樣、怎樣才算正確」。

它適合練習用換算器、計算工具與網頁原型。涉及真實付款、病歷、法律判斷、銀行帳戶或重要個資的系統，需要專業設計與審查。

這週先做一個小作品：輸入美元，換算新臺幣。你負責規格與驗收，AI 協助施工；畫面漂亮、AI 說完成，都不能代替測試。

示範工具

  • 首選：Gemini 免費版。同一段需求可先討論，再用 Canvas 查看網頁雛形，適合第一次接觸程式的人。
  • ChatGPT：可用免費文字聊天拆解需求、產生程式；一般聊天與 Codex 模式的功能資格需分別核對。
  • Claude：免費聊天與 Artifacts 可協助討論、展示成果；這不等於免費取得 Claude Code。

步驟

  1. 打開瀏覽器，登入 Gemini，建立新對話；今天先討論需求。
  2. 寫下使用情境：「我想練習將美元金額換算成新臺幣。」
  3. 決定第一版只做美元轉新臺幣，使用固定練習值 1 USD＝32 TWD。
  4. 畫出文字流程：輸入金額 → 檢查輸入 → 換算 → 顯示結果；輸入不合規則時顯示提醒。
  5. 貼上下方提示詞，檢查 AI 產生的規格，刪掉帳號、付款、資料庫等額外功能。
  6. 把確認的規格留在筆記中，明天依選定路線存成 README.md，或留在本地筆記。

範例提示詞

請當我的程式入門教練，幫我把想法整理成可驗收的規格，
先不要寫程式。請使用繁體中文、台灣用語。

<作品資料>
作品：匯率換算器。
使用者：完全沒寫過程式的成人。
第一版：輸入美元金額，換算新臺幣。
固定練習匯率：1 USD＝32 TWD，這是假設值，不是目前報價。
允許輸入：0與正數，最多兩位小數。
不允許：空白、負數、非數字、超過兩位小數。
結果顯示到小數點後兩位。
第一版離線運作，不需要帳號、付款、資料庫或外部套件。
頁面必須清楚標示「練習資料，非交易報價」。
</作品資料>

請輸出：
1. 150字內的作品說明。
2. 使用者操作流程，包含輸入錯誤時的分支。
3. 第一版必做功能，最多五項。
4. 五個測試案例：輸入、預期結果、檢查理由。
5. 後續可增加的功能，與第一版分開列。

若有不清楚的地方，先列問題，不要自行擴大功能。
不要提供投資或換匯時機建議。

驗收

  • 是／否：規格有清楚寫出匯率方向與單位？
  • 是／否：至少有一個正常案例及一個錯誤輸入案例？
  • 是／否：能用自己的話說出第一版完成的條件？

正常範例

輸入：100 USD，練習匯率 32 TWD／USD。
預期：100 × 32＝3,200.00 TWD，同時顯示練習資料標示。

失敗範例

AI 回答：「將串接銀行帳戶，自動判斷最佳換匯時機。」

辨識方式：新增了規格沒有要求的權限與金融判斷。請它退回單純換算，重新列出第一版範圍。

常見錯誤
  • 只說「做一個好用又漂亮的網站」，沒有輸入、動作與預期結果。
  • 一開始就加多幣別、登入、歷史圖表，遇到問題時不知道是哪一段壞掉。
  • 把 AI 產生的規格當成已完成的作品。
  • 提供真實存款、銀行帳戶或旅遊付款資料；練習用虛構數字即可。
  • 以為「不會寫程式」就不需要理解單位、計算方向與驗收方式。
