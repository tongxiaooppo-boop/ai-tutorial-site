第 20 天｜匯率換算器

★ 最低完成路線先修：第 19 天

第 4 天｜第一個作品：單一 HTML 匯率換算器

白話觀念卡

一個簡單網頁可以把三種內容放在同一份 HTML：HTML 放文字與輸入欄位，CSS 決定外觀，JavaScript 負責按鈕與計算。

今天先用固定練習值，讓計算規則容易驗證。確認功能正確後，再調整字體與顏色。這樣一旦壞掉，比較知道是計算、操作還是外觀出了問題。

AI 預覽中能運作，不代表下載後也能運作。真正的成品要存成 index.html，在自己的瀏覽器重新開啟測試。

示範工具

  • 首選：Gemini 免費 Canvas。可在對話旁查看與調整簡單網頁，再把完整程式存回本機。
  • ChatGPT：可產生完整 HTML；有可用 Canvas 時也能協作，仍須在本機驗收。
  • Claude：免費 Artifacts 可協助展示互動工具；須明確要求可獨立執行的單一 HTML，並核對匯出內容。

步驟

  1. 打開 Gemini 新對話，提供第 1 天規格，要求使用 Canvas；有資格的學員也可在已選定的程式代理內操作。
  2. 貼上下方提示詞，先做計算功能，確認只有一份 HTML，沒有需要另外安裝的框架。
  3. 在 VS Code 的 fx-practice 建立 index.html，貼入完整程式並儲存；不要貼入 Markdown 的三個反引號。
  4. 用檔案總管開啟這份 index.html，測試 100、0、12.5、空白、-1、1.234。
  5. 功能通過後，再請 AI 調整一項外觀，例如加大結果文字；縮窄瀏覽器，確認手機寬度仍能使用。
  6. 重做測試，檢查 diff，再建立存檔點。
git diff -- index.html
git add index.html
git commit -m "完成固定練習匯率換算器"

新檔案第一次加入 Git 前，git diff 可能沒有內容；也要直接開啟新檔檢查。可在暫存後用 git diff --cached 查看。

範例提示詞

請幫我製作一個可獨立執行的匯率換算器，
使用單一index.html，HTML、CSS、JavaScript都放在同一檔案。

<作品規格>
用途：程式入門練習。
語言：繁體中文、台灣用語。
方向：USD轉TWD。
練習匯率：1 USD＝32 TWD。
計算：美元金額乘以32。
金額允許0與正數，最多兩位小數。
空白、負數、非數字、超過兩位小數都要提醒並停止換算。
結果顯示兩位小數，清楚標示原幣與目標幣。
輸入變更後，舊結果要清除或標示尚未重新計算。
功能：金額欄位、換算按鈕、清除按鈕、結果區、錯誤提醒。
畫面：淺色背景、深色文字、有清楚欄位標籤，手機寬度可操作。
必須顯示「固定練習匯率，非即時資料、非交易報價」。
不使用框架、CDN、外部圖片、外部字型、登入或資料庫。
不連線，不傳送使用者輸入。
</作品規格>

請輸出：
1. 完整index.html，不能省略程式。
2. HTML、CSS、JavaScript各負責什麼，各用一句話解釋。
3. 六個人工測試案例與預期結果。
4. 若預覽與本機執行不同，要先檢查哪些地方。

請先讓功能正確，不要增加投資建議或其他功能。

驗收

  • 是／否：下載或貼入後，在自己的瀏覽器能獨立操作？
  • 是／否：正常值算對，錯誤值有提醒，沒有顯示 NaN？
  • 是／否：斷網後固定練習版仍可運作？

正常範例

輸入：12.5 USD。
預期：12.5 × 32＝400.00 TWD，頁面保留固定練習值標示。

失敗範例

輸入：100，結果顯示 3.13 TWD。

辨識方式：可能把乘法寫成除法。用計算機算 100 × 32 核對，回報「方向與公式錯誤」，不要只說「數字怪怪的」。

常見錯誤
  • 檔名其實是 index.html.txt；在檔案總管開啟副檔名顯示再確認。
  • 複製了程式的一部分，或連 Markdown 標記一起貼入。
  • AI 產生需要建置的多檔案專案，卻當成單一 HTML 使用。
  • 修改畫面時，沒有重測計算與錯誤提醒。
  • 把真實換匯紀錄或個資放進範例；也沒檢查 AI 是否加入外部連線。
